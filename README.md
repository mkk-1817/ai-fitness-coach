## AI plan generation

Workout plans (strength, cardio, sports, HIIT, mobility or mixed — with preferred sports & cardio activities), 7-day meal plans and food nutrition estimates are generated by Groq from the user's profile. There is no seeded food catalogue or template fallback: responses are validated with strict Zod schemas (`src/types/ai.ts`) plus a semantic review (`src/lib/groq/plan-review.ts`) and retried with the validation errors before anything is shown or saved.

- Server env: `GROQ_API_KEY` (required), `GROQ_MODEL` (optional, defaults to `llama-3.3-70b-versatile`).
- Supabase: apply `supabase/migrations/20260925000000_ai_generated_plans.sql` to existing projects (fresh projects get the same columns from `supabase/schema.sql`). Plans are stored per user in `workout_plans.plan_data` / `meal_plans.plan_data` under the existing RLS policies; signed-out demo mode keeps history in localStorage.
- `supabase/seed.sql` only seeds equipment and the exercise media reference used to attach verified demo videos.
